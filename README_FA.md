# خانه زبان خانواده ۴

## اجرا
فایل `index.html` را روی GitHub Pages منتشر کنید. برای حالت آفلاین محلی همین فایل کافی است.

## همگام‌سازی دو دستگاه
1. یک پروژه Supabase بسازید.
2. فایل `supabase/schema.sql` را اجرا کنید.
3. URL و کلید عمومی Anon/Publishable را در تنظیمات `APP_CONFIG` ابتدای `index.html` قرار دهید.
4. کلید Service Role را هرگز داخل مخزن قرار ندهید.
5. با یک ایمیل خانوادگی روی دو دستگاه وارد شوید. دستگاه سوم توسط Trigger رد می‌شود.

## مسیرها
- سعید: IELTS، اپلای دکتری، پایان‌نامه و مقالات
- آرزو: A1، خرید، آشپزخانه، مدرسه کودکان و کامپیوتر
- النا: ۱۱ سال، الفبا، فونیک، مدرسه، داستان و علوم
- آریا: ۳ سال، نشست ۵ تا ۸ دقیقه‌ای والد‌همراه


## تصاویر پروفایل
تصاویر تأییدشده آرزو، النا و آریا در `assets/profiles` قرار دارند و برای انتخاب عضو در شروع نشست استفاده می‌شوند. نسخه مستقل تصاویر را در خود HTML جاسازی می‌کند.
