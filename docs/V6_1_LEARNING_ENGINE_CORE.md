# Family Language OS v6.1 — Learning Engine Core

## دامنه نسخه
این نسخه، زیرساخت تصمیم‌گیری و ثبت یادگیری را عملیاتی می‌کند. هدف آن تکمیل همه محتوای A0 تا C2 نیست؛ هدف، ساخت موتوری است که محتوای بعدی را به نشست، تلاش، خطا، تسلط، مرور و ارتقای سطح تبدیل کند.

## اجزای هسته

### 1. Adaptive Session Planner
- برنامه روزانه پایدار بر اساس تاریخ، عضو، زبان، سطح، واحد و هدف.
- اولویت‌دهی به مهارت ضعیف، خطاهای سررسید و کارت‌های مرور.
- نشست ۱۰ مرحله‌ای بزرگسال، مسیر سن‌محور النا و نشست ۶ مرحله‌ای والد‌همراه آریا.
- امکان ادامه همان نشست پس از بستن و بازکردن برنامه.

### 2. Mastery Model
- تسلط فقط از میانگین نمره ساخته نمی‌شود.
- نمره، استقلال، بازیابی، تکمیل و اعتماد در محاسبه وارد می‌شوند.
- حداقل دو عملکرد موفق و پایداری لازم است.
- تکرار همان فعالیت، امتیاز XP تکراری تولید نمی‌کند.

### 3. Unit and Level Gates
- بازشدن واحدها به عملکرد واحد قبلی وابسته است.
- ارتقای سطح به تسلط حداقل ۸۰٪ واحدها، میانگین حداقل ۷۵، کف مهارت و ارزیابی سطح وابسته است.
- آریا مسیر PRE بدون قفل رسمی و بدون آزمون دارد.

### 4. SRS and Error Book
- کارت واژه از فعالیت‌های واقعی ساخته می‌شود.
- زمان مرور با الگوریتم فاصله‌گذاری تعیین می‌شود.
- پاسخ نادرست به‌صورت خودکار وارد خطانامه می‌شود.
- خطا و واژه هر دو تاریخ مرور بعدی دارند.

### 5. Local-first Event Model
- تلاش‌ها و رویدادها شناسه یکتا دارند.
- ادغام رویدادها idempotent و latest-wins است.
- ادغام snapshot، رکوردهای واحد و درس را بر اساس زمان به‌روزرسانی ترکیب می‌کند و کل داده یک دستگاه را کورکورانه جایگزین نمی‌کند.
- محدودیت دو دستگاه در Schema پایگاه داده حفظ شده است.

## مفروضات قفل‌شده
- سعید: ایرانی، بزرگسال، انگلیسی پژوهشی/IELTS/PhD/HSE و آلمانی عمومی.
- آرزو: کارشناسی کامپیوتر، انگلیسی A1 و آلمانی A1، مسیر زندگی واقعی و IT.
- النا: ۱۱ ساله، مسیر مدرسه‌ای، الفبا، فونیک، بازی، داستان و پروژه.
- آریا: ۳ ساله، PRE، والد‌همراه و بدون آزمون رسمی.
- تصاویر واقعی اعضا فقط Crop/Resize/WebP شده‌اند؛ بازسازی چهره با هوش مصنوعی در نسخه نهایی مجاز نیست.

## وضعیت محتوا
- ۱۸۴ واحد ساختاریافته برای انگلیسی و آلمانی از A0 تا C2، به‌علاوه PRE.
- بانک محتوای فعلی برای اثبات موتور است و هنوز Content Final محسوب نمی‌شود.
