# Family Language OS v6 — Rebuild Baseline

v5 یک Demonstrator بود. v6 به‌صورت Learning OS داده‌محور توسعه می‌یابد.

## مسیرها
- سعید: English B1→C1/C2، IELTS، PhD، پژوهش، HSE و معدن؛ Deutsch A0→B2.
- آرزو: English/Deutsch A1→B2؛ زندگی، خرید، آشپزخانه، مدرسه، مهاجرت و IT.
- النا ۱۱ ساله: A0→B1؛ الفبا، فونیک، داستان، علوم، پروژه و ایمنی دیجیتال.
- آریا ۳ ساله: PRE؛ والد‌همراه، ۵ تا ۸ دقیقه، تصویر، صدا و حرکت؛ بدون آزمون رسمی.

## زنجیره داده
Language → Level → Unit → Task → Attempt/Event → Mastery/Error/SRS.

## گیت انتشار
SOURCE → SYNTAX → RUNTIME → ROUTES → TASK → STORAGE → OFFLINE → DEVICE → SYNC → FAMILY ACCEPTANCE.
